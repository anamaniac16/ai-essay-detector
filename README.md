# AI Essay Detector

A sentence-level AI-generated text detector for college admissions essays, built with transparent, inspectable signals — not a chat-model wrapper.


> [!IMPORTANT]
> **CRITICAL DATASET LIMITATION WARNING**
> - **Human Class Sourced from Brown Corpus**: Due to strict firewall sandboxing blocking access to Kaggle and Hugging Face datasets, the "human" class was sourced directly from NLTK's Brown Corpus (specifically the 'belles_lettres' and 'learned' categories of formal, academic prose). It does NOT contain actual student college admissions essays. Results must be interpreted as evaluating general human vs. AI prose differences rather than college admissions essays specifically.
> - **AI Class Generated by Multiple Models**: The AI essays are generated by Google Gemini (40 essays across 3 prompting styles) and a local GPT-2 Small model (10 essays generated using raw next-token continuation).

## How It Works

```
Essay Text
    ↓
GPT-2 (124M, local, CPU) → Token-level log-probabilities
    ↓
Feature Extraction:
  • Perplexity (how "surprised" is GPT-2?)
  • Burstiness (variance of per-sentence perplexity)
  • Sentence length statistics
  • Function word ratio
  • POS-bigram entropy
  • Type-token ratio (vocabulary richness)
    ↓
Trained Classifier (Logistic Regression / XGBoost)
    ↓
Per-sentence highlighting + evidence display
```

**Key design decisions:**
- GPT-2 is used as a **statistical instrument** (log-prob source), NOT as a verdict oracle
- The classifier operates on **named, interpretable features** — every prediction can be explained
- ESL (non-native English) signal is a **separate, independent module** to surface bias risk
- All feature importances are saved and displayed

## Features Extracted

| Feature | Description | AI Signal |
|---------|-------------|-----------|
| `essay_perplexity` | GPT-2 perplexity over full essay | Lower = more predictable = more AI-like |
| `burstiness_std` | StdDev of per-sentence perplexity | Lower = more uniform = more AI-like |
| `burstiness_cv` | Coefficient of variation | Normalized burstiness |
| `avg_sentence_length` | Mean words per sentence | AI tends toward consistent length |
| `sentence_length_std` | StdDev of sentence lengths | Lower = more uniform = more AI-like |
| `function_word_ratio` | Proportion of function words | AI may over/under-use |
| `pos_bigram_entropy` | Shannon entropy of POS bigrams | Lower = more formulaic = more AI-like |
| `type_token_ratio` | Unique words / total words | Vocabulary diversity indicator |
| `avg_log_prob` | Mean token log-probability | Higher (less negative) = more predictable |
| `log_prob_std` | StdDev of token log-probs | Lower = more uniform predictions |

## ESL Bias Check

The detector includes a **separate, independent** ESL signal module that detects
patterns common in non-native English writing:
- Article/preposition irregularities
- Vocabulary sophistication measures
- Sentence complexity distribution
- Repetitive sentence starters

When both AI-likelihood AND ESL signals fire, the app shows an explicit banner
warning the user to treat the score with added caution.
